# NexaHub

Static, free browser-based tools hub for GitHub Pages.

## Deploy
1. Create a GitHub repository named `NexaHub` under the GitHub account `0-umbra`.
2. Upload everything inside this folder to the repository root.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
4. Your expected Pages URL is `https://0-umbra.github.io/NexaHub/`.

The project uses relative paths and does not require a server/database. Favorites, recent tools and theme preferences use localStorage. Image tools and password generation run locally in the browser. QR generation and API-powered AI are marked Coming Soon rather than faked.
